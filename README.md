# 奶jump（NaiWa Jump）

一个 2D 跳跃躲避小游戏，主角是「奶蛙」（NaiWa）。
踩着不断上升的地板往上爬，躲开奶娃和奶嘴，靠奶蛋回血、加分，活得越久分数越高。

> 引擎：团结引擎（Tuanjie）2022.3.62t15 / Unity 2022.3
> 场景：`Assets/Scenes/SampleScene.scene`

---

## 操作

| 按键 | 作用 |
| --- | --- |
| `A` / `D` | 左右移动（只有站在地面上才能跑） |
| `空格` | 跳跃（必须站在地面上） |
| `S` | 让脚下的地板变成 Trigger，直接穿下去 |

> 空中不能触发跑步动画：只有 `run` 为真 **且** `isGrounded` 为真时才会跑。

---

## 核心规则

### 血量

- 初始 **5 点**，上限 **5 点**（与血条格数一致）。
- 血条用 5 个格子显示，血量变化时实时刷新。

| 事件 | 血量变化 |
| --- | --- |
| 踩到奶蛋 | **+2** |
| 撞到奶嘴 | **-2** |
| 踩到奶娃 | **-1** |
| 掉出死亡区（DeathField） | **直接清零** |
| 每满 10 分 | **+1** |

### 分数

- 每 **2 秒** 自动 **+1 分**。
- 每踩一次奶蛋 **+11 分**。
- 每满 **10 分** 回复 **1 点血**（只在刚好满 10 的那一帧触发一次）。

### 地板类型

| 类型 | 效果 | 上升速度 |
| --- | --- | --- |
| **奶眼** | 普通地板，可以站，没有额外效果 | 2 |
| **奶蛋** | 踩上去 **+2 血、+11 分**，**0.25 秒后**消失并生成一块新地板；踩上时 naiKobe 背景出现，地板消失时跟着淡出 | 2.6 |
| **奶娃** | 踩上去 **-1 血**，但可以站在上面 | 1.8 |

- 所有地板会持续上升，到达 `y > 5.5` 时自动销毁，并生成一块新地板。
- 按 `S` 可以把脚下的地板变成 Trigger，直接穿过去（穿过后立刻视为离地，不能跳/跑）。

### 死亡

血量归零时：

1. 角色保持 **受伤（hurt）姿态**，关闭自身碰撞体，**持续下落**；
2. `background` 的 Order in Layer 变为 **-2**，`background2` 变为 **-1**；
3. **分数和血量都被锁定**，任何碰撞、触发器、加分/回血都不会再改变它们；
4. **0.6 秒后**弹出死亡结算界面，显示最终分数。

## 生成规则

- **生成位置**：`x ∈ [-4.2, 4.2]`，`y = -5.7`。
- **概率**：

| 类型 | 概率 |
| --- | --- |
| 奶眼 | **50%** |
| 奶蛋 | **30%** |
| 奶娃 | **20%** |

- **防止重叠**：
  - 每次生成最多尝试 **20 个**随机位置；
  - 要求与「出生高度附近」已有地板的水平距离 ≥ **0.9**；
  - 如果 20 次都找不到空位，就用这 20 个候选里**最不挤**的位置硬放，保证地板不断档。

## 界面

### 开始界面

- 背景：`NaiWa` 立绘铺满整屏（按比例放大，不变形）；
- 正中间标题：**「奶jump」**（深黄色、加粗、带投影）；
- 按钮：**开始**、**退出**（naiYan 背景）。

### 死亡结算界面

- 半透明黑色遮罩 + `naiDan` 背景；
- 分数文字：加粗、深色、带描边；
- 按钮：**重新开始**、**返回主界面**、**退出**（纯色按钮）。

| 按钮 | 功能 |
| --- | --- |
| 开始 | 进入游戏 |
| 重新开始 | 直接重开一局（不经过开始界面） |
| 返回主界面 | 回到开始界面（需要再点「开始」才进游戏） |
| 退出 | 关闭游戏（编辑器里停止运行） |

## 运行方式

### 方式一：直接运行成品（Windows，无需引擎）

仓库里的 `Nai_Jump/` 就是打包好的可执行版本：

1. 进入 `Nai_Jump/` 目录；
2. 双击 **`奶jump.exe`** 即可开始游戏。

> `Nai_Jump/` 整个文件夹（约 96 MB）要一起保留——exe 依赖同目录下的 `奶jump_Data/`、`TuanjiePlayer.dll`、`MonoBleedingEdge/` 等文件，**只拷 exe 是打不开的**。

### 方式二：用引擎打开工程

1. 用团结引擎 / Unity 2022.3 打开项目；
2. 打开 `Assets/Scenes/SampleScene.scene`；
3. 点击 Play。

> UI 不需要手动挂到场景里：`UIManager` 会在运行时自动创建，并监听每次场景加载（重新开始 / 返回主界面都能正常重建界面）。

## 小提示

- 地板是往上走的，**不要一直待在原地**，否则会被地板顶到奶嘴。
- 奶蛋是主要补给：回血 + 加分，但踩完 0.25 秒就消失，记得马上找下一块。
- 每 10 分回 1 血，所以活得越久越耐打。
- 奶娃虽然扣血，但也能站，可以用来保命。
